# Document Vault

A personal document storage and retrieval web application.

## Problem

Digital documents are often scattered across phones, laptops, email, messaging apps, and cloud storage.

Document Vault aims to provide a simple place to store, organize, search, and access important documents from any device.

## MVP

- User registration and login
- User profile
- Document upload
- Document naming
- Document categorization
- Document search
- Document viewing
- Document downloading
- Trash for deleted documents
- Document restoration
- Permanent document deletion
- Automatic deletion after 30 days

## Document Categories

- Personal
- Educational
- Professional
- Business
